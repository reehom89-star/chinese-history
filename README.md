# 华夏五千年 · 中国历史百科

从盘古开天辟地的神话，到此时此刻的新时代 —— 一部可以「看、读、玩」的中国历史网站。

> 为「嘻嘻」制作 · 纯静态站点，无需安装任何依赖，双击 `index.html` 即可使用。

## ✨ 功能

- **🏮 时间轴首页**：12 个历史阶段卡片（各配大图封面），从神话传说到当代；顶部还有**按真实年代比例的朝代时间轴条**，悬停看朝代、点击直达
- **🔍 全站搜索**：顶栏搜索框实时检索故事 / 发明 / 人物 / 成语，点击结果直达对应阶段
- **📖 阶段详情**：每个阶段包含
  - 重点故事（7~8 个，全部配 AI 插画）
  - 重大发明与成就（6~7 项）
  - 重点人物（7~8 位，含历代君王，配君王群像图）
  - 关联成语故事（6~8 个，出处 + 典故 + 含义）
  - 你知道吗冷知识（2 条）
  - 地理足迹（本阶段重要地点，点击跳转地图）
  - 上一阶段 / 下一阶段导航
- **🗺️ 交互地图**：真实中国地图（35 省级轮廓 + 南海诸岛小图），49 个历史点位可点击，支持按阶段筛选；**12 个朝代的疆域叠加层**（选中阶段即显示该朝代疆域，如唐西至中亚、元北至 52°N）；**4 条历史路线动画**（陆上丝绸之路 / 海上丝路·郑和 / 万里长征 / 京杭大运河），国际段途经点附**精确经纬度 + Google 地球链接**
- **🎯 趣味问答**：综合挑战或按阶段答题（每阶段 8 题，共 96 题），答对 +10 分、即时解析、星级评价、最佳成绩与历史记录（保存在浏览器本地）

## 🖼️ 关于图片

站点 102 张配图均由 gpt-image-2 生成（统一"现代国风扁平插画"风格：奶油底、朱砂红/黛蓝/金/玉绿配色、无文字水印），分两批生成后压缩为 JPEG（总 22MB）。
